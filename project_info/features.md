# Subby — Feature Surface

## 1. Digital menu hosting
- Hosted, per-venue menu page (custom subdomain or path).
- Sections, items, modifiers, allergens, dietary tags.
- Photo support and seasonal/availability toggles.
- QR-code generation per table/zone.
- Real-time edits — no app redeploy needed.

## 2. Payment integration
- Pluggable payment providers (Stripe primary; SumUp/Adyen planned).
- Pay-at-table via QR.
- Split bills (by item or by share).
- Tipping with configurable defaults.
- Refund and partial refund from operator dashboard.

## 3. Table bookings
- Public booking page per venue.
- Configurable shifts, table layout, party-size limits, deposits.
- Walk-in and reservation modes side by side.
- SMS/email confirmation and reminders.
- Booking → arrival → bill flow links the reservation to the eventual payment.

## 4. Loyalty schemes
- Stamp-card style ("buy N, get 1") and points-based modes.
- Auto-issue on payment — no separate scan step.
- Redemption rules: minimum spend, time windows, single-use codes.
- Customer wallet view (web, no app install required).

## 5. Operator dashboard
- One-screen view of today's bookings, live tabs, and revenue.
- Menu editor.
- Staff accounts with role-based permissions.
- Daily/weekly/monthly reports.

## 6. Customer-facing surface
- No app install required — everything works via web.
- Single identity across menu, booking, payment, loyalty.
- Optional account for storing payment method and loyalty stamps.

## Feature priority (v1 cut)
1. Menu hosting + QR
2. Payments (Stripe only)
3. Bookings
4. Loyalty (stamp mode only)
5. Operator dashboard (read-only reports first, editing second)

Multi-provider payments, points-based loyalty, and multi-site management are post-v1.
